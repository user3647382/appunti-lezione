# Appunti Lezione — app per telefono e tablet

App web per registrare una lezione su iPhone, iPad o Android: audio, slide (PDF), appunti, disegni,
foto della lavagna e momenti importanti. Tutto resta sul dispositivo; a fine lezione si invia un file
`.lezione` a un Mac con Appunti Lezione, che trascrive la registrazione e prepara il documento di studio.

Apri l'app: https://user3647382.github.io/appunti-lezione/
